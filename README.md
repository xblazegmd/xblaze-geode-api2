# Xblaze's Geode API
A bunch of utils for my Geode mods

You can add this to your mod's `CMakeLists.txt`
```cmake
CPMAddPackage("gh:xblazegmd/xblaze-geode-api2@3.0.0")
target_link_libraries(${PROJECT_NAME} xblaze-geode-api)
```

This is fully integrated into your mod, so you do not have to add any dependencies!
